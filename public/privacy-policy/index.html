隱私權政策

生效日期：2026 年 7 月 16 日

國教行動聯盟（下稱「本聯盟」，英文全名 Action Alliance on Basic Education，縮寫 AABE）為民間團體，重視使用者與社會大眾之隱私權。本政策說明本聯盟於提供數位服務時，如何蒐集、使用、保存個人相關資訊。使用本服務前，請詳閱本政策；若不同意本政策內容，請勿使用本服務。

第一條　適用範圍

本政策適用於本聯盟所提供之數位服務，包括官方網站 aabe.org.tw、政策專頁 policy.aabe.org.tw，以及「AABE 聲量觀測站」等平台（以下合稱「本服務」）。

第二條　本聯盟蒐集之資訊

本服務不要求一般使用者註冊帳號或提供個人資料即可瀏覽。本聯盟透過第三方平台之公開應用程式介面（API，包括但不限於 Meta Threads API 等）取得之資訊，僅限於「公開貼文之中繼資料」，例如：貼文標題或摘要、貼文連結、發布日期，以及帳號之公開顯示名稱。本聯盟不蒐集使用者之密碼、私訊內容、電話、電子郵件等個人身分資訊，亦不為任何使用者建立個人檔案（profile）。

第三條　資料來源

前條資訊來源包括 Google News、YouTube、PTT、Podcast、Dcard、Mobile01、巴哈姆特，以及 Meta Threads API 等第三方平台之公開資料介面。本聯盟使用上述第三方 API 時，均遵守各平台之開發者條款與使用政策。

第四條　使用目的

本聯盟蒐集、彙整前述公開中繼資料，僅用於：（一）教育政策公共討論之觀測；（二）聲量統計與趨勢彙整；（三）倡議研究與政策論述佐證。本服務不用於商業行銷、廣告投放，或任何個人化商業用途。

第五條　資料保存與刪除

本服務所彙整之資料具快取（cache）性質，用於統計呈現，並非永久保存之個人資料庫。如任何人發現特定貼文之中繼資料出現於本服務，並希望移除，請依第九條聯絡方式提出申請，本聯盟將於合理時間內處理。

第六條　第三方分享

本聯盟不販售、不出租、不移轉使用者或第三方之資料予任何其他公司或個人，僅於本政策所載目的範圍內使用；法令另有要求者不在此限。

第七條　Cookie 與追蹤技術

本服務目前不使用 Cookie 或其他追蹤技術蒐集使用者之瀏覽行為。

第八條　兒少保護

本聯盟以促進兒童及少年權益為宗旨。本服務不針對兒少使用者蒐集個人資料，亦不主動蒐集任何使用者之年齡或身分別資訊。

第九條　聯絡方式

如對本政策有任何疑問，或欲申請資料移除，請聯絡：claude@aabe.org.tw。

第十條　生效日期與修訂

本政策自 2026 年 7 月 16 日起生效。本聯盟得因應法令或服務調整修訂本政策，修訂後將公告於本頁面，並更新生效日期。
